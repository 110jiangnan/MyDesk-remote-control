# 自建中继（coturn）—— 手把手教程

MyDesk 默认用我们的公共中继服务器，开箱即用。如果你希望会话流量走**你自己**的服务器
（出于隐私、合规，或者用量很大），可以照下面一步步自建一台中继。**一行命令**搞定。

> 本教程假设你**完全没接触过服务器**。照着做就行，每一步都写清楚了。
> 只需要一台"云服务器"和 15 分钟。

---

## 先花 1 分钟搞懂要做什么

- 你要买一台**云服务器**（也叫 VPS、云主机）——它就是一台一直开着、放机房里的电脑，
  帮你的两台设备牵线传画面。
- 系统**强烈建议选 Ubuntu 22.04 / 24.04**（本教程和脚本都按 Ubuntu 写，最省心）。
- 大概花费：**大陆 ¥30–¥100/月**，**海外 $5–$10/月**。

---

## 第一步：买一台云服务器

### 1.1 先定地区（重要）

| 你的设备在哪 | 买哪里的服务器 |
|---|---|
| 两台设备都在**中国大陆** | 买**中国大陆**的服务器（延迟最低、速度最快） |
| 两台设备都在**海外** | 买**香港 / 新加坡 / 日本 / 美国**等离你近的节点 |
| 一大陆一海外 | 中继救不了跨洋，建议就近各买一台（或就用默认公共中继） |

### 1.2 去哪买

**中国大陆（推荐给大陆用户）：**

| 平台 | 怎么买 | 说明 |
|---|---|---|
| 阿里云 | 控制台搜「轻量应用服务器」 | 最主流，新手友好 |
| 腾讯云 | 控制台搜「轻量应用服务器」 | 同上，性价比常不错 |
| 华为云 | 控制台搜「云耀云服务器 / 轻量」 | |
| 京东云 / UCloud / 百度智能云 | 搜「轻量 / 云服务器」 | 备选 |

> 大陆买服务器要**实名认证**（身份证），付款用支付宝/微信都行。
> **只做中继不用备案**（备案是给 80/443 建站用的，这里用不到）。

**海外（推荐给海外用户）：**

| 平台 | 特点 |
|---|---|
| **Vultr** | 按小时计费、节点多、开通快，新手首选 |
| **DigitalOcean** | 界面最友好，$6/月，文档全 |
| **Linode (Akamai)** | 老牌稳定 |
| **Hetzner** | 便宜量大（但主要在欧洲/美国） |
| **AWS Lightsail** | 亚马逊的简化版云服务器 |
| **Oracle Cloud** | 有**永久免费**实例（抢得到的话） |

> 海外买服务器一般**用信用卡 / PayPal**付款。

### 1.3 买什么配置

- **CPU / 内存**：最低 **1 核 1G** 就够（coturn 很轻）。
- **带宽 / 流量**：**这是重点**。中继要转发画面，别买太小——
  - 选「按带宽」的：**≥ 5 Mbps**（越大越流畅）。
  - 选「按流量」的：**≥ 1TB / 月**。
- **系统镜像**：选 **Ubuntu 22.04 LTS** 或 **Ubuntu 24.04 LTS**。
- 其它（硬盘 20G、快照等）用默认即可。

### 1.4 买完，记下两样东西

1. **公网 IP**：形如 `203.0.113.7`（控制台首页就能看到）。
2. **root 密码**：下单时设的；忘了就在控制台点「**重置密码**」。

## 第二步：连上这台服务器

打开你电脑上的命令行，登录服务器：

**Windows 10/11：**
1. 开始菜单搜 **PowerShell**，打开。
2. 输入下面这行（把 IP 换成你的），回车：
   ```
   ssh root@你的公网IP
   ```
3. 第一次会问 `Are you sure...?`，输入 `yes` 回车。
4. 提示 `password:` 时输入你的 root 密码。
   **注意：输密码时屏幕上不会有任何显示，这是正常的**，输完直接回车。

**macOS / Linux：**
打开「终端」，同样输入 `ssh root@你的公网IP`，后面步骤一样。

看到命令提示符变成类似 `root@myhost:~#` 就说明**登录成功**了。

---

## 第三步：一条命令部署

在服务器上（就是刚登录的那个黑框里）运行：

**大陆服务器（用 Gitee，快）：**
```bash
curl -fsSL https://gitee.com/jiangnan-java/MyDesk-remote-control/raw/master/self-host/deploy-coturn.sh | sudo bash
```

**海外服务器（用 GitHub）：**
```bash
curl -fsSL https://raw.githubusercontent.com/110jiangnan/MyDesk-remote-control/master/self-host/deploy-coturn.sh | sudo bash
```

脚本会自动：装 Docker（没有的话）→ 探测公网 IP → 生成随机**静态密钥**和自签名证书 →
写好配置 → 启动 coturn 容器 → 尝试放行系统防火墙 → **把要填进 App 的值打印出来**（在最后一段）。

> 想先看脚本内容再跑？可以用浏览器打开上面任意链接，复制保存成文件后运行 `sudo bash deploy-coturn.sh`。

---

## 第四步：放行端口（⚠️ 最容易漏的一步）

服务器默认把大部分端口关着。**光在系统里放行不够——一定要去云服务商的控制台放行**，
否则外网根本连不进来。

脚本已经尽量帮你放了**系统防火墙**（ufw），但**云控制台的「安全组 / 防火墙」是另外一层，必须手动开**。

**去哪开：**

| 平台 | 位置 |
|---|---|
| 阿里云 / 腾讯云 / 华为云 / 京东云 | 控制台 → **安全组**（或"防火墙"）→ 你的实例 |
| Vultr | 控制台 → **Firewall** |
| DigitalOcean | 控制台 → **Networking → Firewalls** |
| AWS Lightsail | 实例 → **Networking → Firewall** |
| Oracle Cloud | VCN → **Security Lists** |

**怎么开：** 新建一条「**入站规则（Inbound）**」，来源填 `0.0.0.0/0`（表示允许所有 IP），
把这几个端口都放行：

| 协议 | 端口 | 用途 |
|---|---|---|
| TCP | 3478 | TURN / STUN |
| UDP | 3478 | TURN / STUN |
| TCP | 5349 | TURN over TLS |
| UDP | 5349 | TURN over DTLS |
| UDP | 49152 - 65535 | 中继媒体端口 |

> 有些平台可以一次填「端口范围」，那就按上表分几条加；UDP 的那几条**别漏**，漏了会连上没画面。

---

## 第五步：把打印的值填进 MyDesk

脚本最后会打印一段，形如下面。把它填进 App 的**自定义中继**弹窗
（设置 → 自定义中继 → 新增配置）：

| 打印的值        | MyDesk 里的字段             | 示例                             |
|-----------------|-----------------------------|----------------------------------|
| 名称 Name       | 名称                        | `My relay`                       |
| TURN server     | TURN 服务器                 | `turn:203.0.113.7:3478`          |
| STUN server     | STUN 服务器                 | `stun:203.0.113.7:3478`          |
| 静态密钥        | 静态密钥（鉴权方式=静态密钥）| `9f2c…`（脚本打印的那串）        |
| 带宽            | 服务器带宽 (Kb/s)           | 100 Mbps 上行填 `102400`         |

> **鉴权方式请选「静态密钥」。** 这套部署让 coturn 跑在 `use-auth-secret` 模式，
> 由静态密钥完成鉴权。**不要**对它用「用户名/密码」选项。

保存后：按需为**控制时 / 被控时**启用该配置，再到**我的设备**里打开对应设备的开关。
启用侧之后的连接就会走你自己的服务器。

> 中继功能需要付费档位（中继权限 / VIP）。

## 验证

```bash
# 看容器日志（在服务器上运行）
docker logs -f mydesk-coturn
```

然后在 App 里打开中继、发起一次远控。连上即可。若连不上，看下面的排障。

> ⚠️ **重要：自定义中继是"独占"的。** 一旦启用，连接就**只**走它——**它挂了就会连不上，
> 而且不会自动退回公共中继**。欠费停机、coturn 崩了、IP 变了、密钥改了没同步、安全组被动过，
> 都会变成"连不上"。所以：
> - **启用前先用一次真实远控跑通**，确认没问题再长期依赖；
> - **保持服务器在线**——别欠费、别关机；
> - 换了 IP / 改了密钥，记得同步更新 App 里的配置；
> - 连不上时，先在 App 里**关掉这个中继开关**——关掉即回退到公共中继，可立即验证是不是中继的锅。
>
> 🛡️ MyDesk 会**每小时自动检测**已启用的中继；连不上时会弹窗提醒你。你也可以在「自定义中继」页顶部打开
> **「中继连不上时自动关闭」**，让它探测失败时自动关掉、回退公共中继。

## 日常管理

```bash
# 看日志
docker logs -f mydesk-coturn

# 轮换静态密钥（之后要在 App 里重新粘贴）
rm /opt/mydesk-coturn/turnserver.conf && sudo bash deploy-coturn.sh

# 升级容器
docker rm -f mydesk-coturn && sudo bash deploy-coturn.sh

# 卸载
docker rm -f mydesk-coturn && rm -rf /opt/mydesk-coturn
```

## 排障

- **连上了但走了公共中继** —— 该配置没在这一侧启用。检查 控制时 / 被控时 开关和设备开关。
- **鉴权失败（日志出现 `401`）** —— 确认 App 里选的是**静态密钥**，且密钥完全一致
  （从脚本输出重新粘贴）。
- **能到服务器但没有画面** —— 十有八九是**端口没放全**：回第四步，确认云控制台安全组里
  UDP 3478、UDP 5349、UDP 49152-65535 都开了。
- **只在部分网络能用** —— 改用 5349 的 `turns:`（TLS）地址；很多公司网络会封普通
  UDP/TCP，但放行 TLS。
- **CentOS / RHEL 开了 SELinux** —— 给脚本里的挂载加 `:Z`，例如
  `-v "$DIR/turnserver.conf:/etc/coturn/turnserver.conf:ro,Z"`。
- **NAT 后面（网卡是内网 IP）** —— 传 `--ip <你的公网IP>`，让 coturn 上报正确地址。
