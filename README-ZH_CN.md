# MyDesk

一个还在努力长大的远程控制工具。

---

## 它是做什么的

MyDesk 是一款跨平台的远程控制软件，让你能用自己的手机或另一台电脑，随时连上自己的电脑：

- **跨平台**：Windows / macOS（暂时未上架） / Linux （暂时未上架），配上 iOS（暂时未上架） / Android 手机，都能互相连
- **实时画面**：远端画面通过 WebRTC 低延迟传输，看得到，也能动手操作
- **隐私屏**：被控端可以遮住本地屏幕，防偷窥，也不会误碰鼠标键盘
- **剪贴板共享**：两台设备之间复制粘贴文字，不用再靠微信传
- **可自建中继**：一条命令部署你自己的 coturn 中继，会话流量走你自己的服务器、不经过我们；重度用户也不会因为用量大被限速或劝退。见 [self-host/](self-host/README-ZH_CN.md)
- **Web 端**：控制端不用装任何东西，从任意浏览器连回你的电脑

## 可自建中继

不想让会话依赖我们的服务器？你可以自建中继——**一条命令**搞定，数据不经过我们。
这和我们自己的中继节点用的是同一套机制。详细步骤和部署脚本在
[self-host/](self-host/README-ZH_CN.md)。

## 为什么会有它

市面上的远控软件要么贵、要么隐私上让人不太放心、要么功能堆得太满反而难用。我们想做一款 **轻量、透明、够用就行** 的远控工具，把常用场景做好。

## 目前的状况（请多担待）

说实话，它还远没有到"完善"的程度：

- 移动端和部分平台的功能还在打磨，细节可能有不如意
- 某些极端网络环境下，连接可能不稳定
- 文档还不全，遇到问题可能需要一点耐心

所以它现在更像一个 **半成品**——但我们希望它在真实使用中一点一点变好，而不是关起门来自己憋。
